## Slide 2 — Problem
- RSVPs don't prove attendance
- Hosts juggle forms, WhatsApp, and spreadsheets
- USDC and mobile money aren't supported by legacy ticketing
- Attendees lose proof they attended

---

## Slide 3 — Solution
- One host dashboard: create, sell tickets, roster, QR, export
- Wallet + email registration
- USDC on Base + mobile-money payment references
- Verifiable check-in flow

---

## Slide 4 — Product (live)
- Create event (capacity, banner, VIP, payment modes)
- Register (wallet or email)
- Manage at /organizer
- Verify at door via QR

Stack: Next.js, Supabase, Wagmi, Base USDC

---

## Slide 5 — How it works
1. Host creates event → link + verification code  
2. Attendees register and pay  
3. Check-in at event  
4. Host exports roster and owns attendance data

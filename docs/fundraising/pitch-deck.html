Problem

Events still run on trust, not proof

  • RSVPs ≠ attendance — sponsors and hosts can’t trust who actually showed up.
  • Fragmented tools — forms, WhatsApp, spreadsheets, and generic ticketing don’t talk to each other.
  • Payment gaps — crypto communities want USDC; local markets want mobile money — incumbents do neither well.
  • No portable record — attendees lose proof they were there when the event ends.
Gate Protocol2 / 12

Solution

One protocol for sign-up, payment, and check-in

  • Host dashboard — create events, set ticket price, manage buyers and rosters, export CSV, share QR.
  • Wallet + email registration — organizers without a wallet can still run full events.
  • USDC on Base + mobile-money references for paid tickets in emerging markets.
  • Cryptographic verification — unique event codes and on-chain-ready attendance flow.

How it works

Organizer → attendee → proof

  • 1. Host creates event and gets a verification code + registration link.
  • 2. Attendees register (wallet or email) and pay if required.
  • 3. At the event, attendees scan QR / code to verify check-in.
  • 4. Host sees live roster, exports data, and owns the attendance record.

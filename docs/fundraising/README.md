# Fundraising materials (500 Global)

Files for pitch deck link + cap table upload.

## Cap table

| File | Use |
|------|-----|
| `cap-table.csv` | Upload to 500 form, or open in Excel/Google Sheets |
| `cap-table.html` | Print to PDF: open in Chrome → **Ctrl+P** → **Save as PDF** |

**Before submit:** Update incorporation entity name and date if you have legal docs.

## Pitch deck

| File | Use |
|------|-----|
| `pitch-deck.html` | Open in Chrome → **Ctrl+P** → **Save as PDF** (landscape, 12 pages) |
| `pitch-deck-slides.md` | Copy/paste into [Google Slides](https://slides.google.com) |

### Get a shareable link (required by 500)

1. Export PDF from `pitch-deck.html` (or build slides in Google Slides from `pitch-deck-slides.md`).
2. Upload PDF to **Google Drive**.
3. Right-click → **Share** → **Anyone with the link** → **Viewer**.
4. Test in **incognito** — paste that URL in the application.

### Before submit

- Slide 8: add your real event/registration counts.
- Slide 10: add your LinkedIn URL.
- Replace `gatefy.app` with your live URL if different.
